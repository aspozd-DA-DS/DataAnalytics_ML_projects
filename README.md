|------------------|------------------|-------|-------|
|[Анализ ценовых факторов на рынке смартфонов](01_Kaggle_Price-phone-analysis-master)| EDA, визуализация, метрика доступности «цена/зарплата», проверка гипотез и выявление арбитражных возможностей на рынке смартфонов в 5 странах|Python, pandas, numpy, seaborn, matplotlib, scikit-learn <br> обработка данных, дубликаты, пропуски,  группировка, сортировка|[Kaggle Mobiles Dataset (2025)](https://www.kaggle.com/datasets/abdulmalik1518/mobiles-dataset-2025)|
|[HR Burnout Lab: прогноз риска выгорания сотрудников](02_Kaggle_HR_Burnout_Lab)| Полный цикл ML-проекта: от сбора данных до бизнес-рекомендаций. EDA, feature engineering, построение и сравнение 7 моделей бинарной классификации (Logistic Regression, Decision Tree, Random Forest, XGBoost, LightGBM, CatBoost) для предсказания выгорания сотрудников. Особый акцент на Recall (F2-score) как основной метрике (важнее не пропустить выгорание). Сегментация сотрудников по риску, проверка статистических гипотез, формулировка HR-рекомендаций на основе интерпретации признаков.|Python, pandas, numpy, seaborn, matplotlib, scikit-learn, LightGBM, CatBoost, XGBoost, phik, scipy|[Synthetic HR Burnout Dataset](https://www.kaggle.com/datasets/ankam6010/synthetic-hr-burnout-dataset/)|
|[Maternal Health Risk: прогноз рисков беременности](03_Kaggle_Maternal_Health_Risk)| Полный ML-проект по многоклассовой классификации уровня риска беременности (low/mid/high) на основе физиологических показателей. Включает EDA, feature engineering, проверку гипотез, построение и сравнение моделей (LogReg, Tree, RF, XGBoost, LGBM, CatBoost), интерпретацию признаков и рекомендации для врачей. Основная метрика — F1-macro, критический фокус на Recall для high risk. | Python, pandas, numpy, seaborn, matplotlib, scikit-learn, CatBoost, XGBoost, LightGBM, scipy, phik |[Kaggle Maternal Health Risk Dataset](https://www.kaggle.com/datasets/csafrit2/maternal-health-risk-data) |
|[Forecast Direction: прогнозирование направления движения цены](04_Forecast_Direction_OHLCV)| Полный ML-проект по бинарной классификации направления движения цены финансового инструмента на следующий день. Включает EDA для временных рядов, feature engineering (лаг-признаки, скользящие окна, технические индикаторы), проверку стационарности и сезонности, обучение моделей с TimeSeriesSplit (LogReg, Decision Tree, RF, XGBoost, LightGBM), калибровку вероятностей, SHAP-интерпретацию. Основной фокус — максимизация Recall для класса «рост» (не пропустить движение) при сохранении интерпретируемости модели. | Python, pandas, numpy, seaborn, matplotlib, scikit-learn, XGBoost, LightGBM, SHAP, statsmodels, phik | Синтетический OHLCV датасет (2014–2024) |
