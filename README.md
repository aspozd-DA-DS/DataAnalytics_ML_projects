Включает EDA, feature engineering, проверку гипотез, построение и сравнение моделей (LogReg, Tree, RF, XGBoost, LGBM, CatBoost), интерпретацию признаков и рекомендации для врачей. Основная метрика — F1-macro, критический фокус на Recall для high risk. | Python, pandas, numpy, seaborn, matplotlib, scikit-learn, CatBoost, XGBoost, LightGBM, scipy, phik |[Kaggle Maternal Health Risk Dataset](https://www.kaggle.com/datasets/csafrit2/maternal-health-risk-data) |

Включает EDA для временных рядов (декомпозиция, ADF-тест, ACF/PACF, сезонность), расширенный feature engineering (лаг-признаки, скользящие окна, технические индикаторы RSI/MACD, сентимент-оценки, календарные признаки). Проведена проверка готовых индикаторов на соответствие стандартным формулам, анализ утечек сентимента. Выполнен отбор 23 стационарных признаков с исключением сырых цен для предотвращения переобучения на тренде. Реализована строгая временная валидация TimeSeriesSplit (train 2010–2045, valid 2046–2053, test 2054–2062) и масштабирование RobustScaler без утечек. Сравнены 5 моделей (LogReg, Decision Tree, Random Forest, XGBoost, LightGBM) с подбором гиперпараметров через GridSearchCV. Лучшая модель — RandomForest (n_estimators=1000, max_depth=9, max_features=5) достигла VALID F1 = 0.634, TEST F1 = 0.684, Recall = 97.1% (поймано 930 из 958 ростов). Оптимальный порог = 0.35 даёт F1 = 0.684. Проведена калибровка вероятностей (Platt scaling, isotonic), выбор порога под разные стратегии (агрессивная, сбалансированная, консервативная). LSTM продемонстрировала F1 = 0.757 на валидации. Выполнена глубокая интерпретация: feature importance (close_position — 13%, rsi_lag1 — 10.8%, macd_hist — 9.4%), SHAP-анализ (macd_hist — главный дифференциатор TP vs FP), стабильность признаков во времени, анализ ошибок (FP при высокой волатильности, FN при экстремальной перепроданности). Сформулированы практические инсайты и рекомендации для торговой стратегии.| Python, pandas, numpy, seaborn, matplotlib, scikit-learn, XGBoost, LightGBM, SHAP, statsmodels, phik, TensorFlow/Keras (LSTM) | [Stock Market Dataset for Predictive Analysis](https://www.kaggle.com/datasets/s3programmer/stock-market-dataset-for-predictive-analysis) |

|[HR Burnout Lab: Employee Burnout Risk Prediction](02_Kaggle_HR_Burnout_Lab)| Full ML project cycle: from data collection to business recommendations. EDA, feature engineering, building and comparing 7 binary classification models (Logistic Regression, Decision Tree, Random Forest, XGBoost, LightGBM, CatBoost) to predict employee burnout. Special focus on Recall (F2-score) as the main metric (missing burnout is the costlier error). Employee risk segmentation, statistical hypothesis testing, and HR recommendations based on feature interpretation. | Python, pandas, numpy, seaborn, matplotlib, scikit-learn, LightGBM, CatBoost, XGBoost, phik, scipy | [Synthetic HR Burnout Dataset](https://www.kaggle.com/datasets/ankam6010/synthetic-hr-burnout-dataset/) |
|[Maternal Health Risk: Pregnancy Risk Prediction](03_Kaggle_Maternal_Health_Risk)| Full ML project on multiclass classification of pregnancy risk level (low/mid/high) based on physiological indicators. Includes EDA, feature engineering, hypothesis testing, building and comparing models (LogReg, Tree, RF, XGBoost, LGBM, CatBoost), feature interpretation, and recommendations for doctors. Main metric is F1-macro, with a critical focus on Recall for the high-risk class. | Python, pandas, numpy, seaborn, matplotlib, scikit-learn, CatBoost, XGBoost, LightGBM, scipy, phik | [Kaggle Maternal Health Risk Dataset](https://www.kaggle.com/datasets/csafrit2/maternal-health-risk-data) |
|[Forecast Direction: Price Movement Direction Forecasting](04_Forecast_Direction_OHLCV)| Full ML project on binary classification of a financial instrument's next-day price direction. Includes time series EDA, feature engineering (lag features, rolling windows, technical indicators), stationarity and seasonality checks, model training with TimeSeriesSplit (LogReg, Decision Tree, RF, XGBoost, LightGBM), probability calibration, and SHAP interpretation. The main focus is maximizing Recall for the "growth" class (not missing a move) while keeping the model interpretable. | Python, pandas, numpy, seaborn, matplotlib, scikit-learn, XGBoost, LightGBM, SHAP, statsmodels, phik | Synthetic OHLCV dataset (2014–2024) |
|[Stock Market Predictor: Price Movement Direction Forecasting](05_Stock_Market_Predictor_OHLCV)| Full ML project on binary classification of a stock's next-day price direction using simulated OHLCV data (13,647 trading days, 2010–2062). Includes time series EDA (decomposition, ADF test, ACF/PACF, seasonality) and extended feature engineering (lag features, rolling windows, technical indicators RSI/MACD, sentiment scores, calendar features). Pre-computed indicators were checked against standard formulas, and sentiment leakage was analyzed. Selected 23 stationary features, excluding raw prices to prevent overfitting to the trend. Implemented strict temporal validation with TimeSeriesSplit (train 2010–2045, valid 2046–2053, test 2054–2062) and leakage-free RobustScaler scaling. Compared 5 models (LogReg, Decision Tree, Random Forest, XGBoost, LightGBM) with hyperparameter tuning via GridSearchCV. The best model, RandomForest (n_estimators=1000, max_depth=9, max_features=5), reached VALID F1 = 0.634, TEST F1 = 0.684, Recall = 97.1% (930 of 958 up-moves caught). An optimal threshold of 0.35 gives F1 = 0.684. Probability calibration (Platt scaling, isotonic) and threshold selection for different strategies (aggressive, balanced, conservative) were performed. An LSTM reached F1 = 0.757 on validation. Deep interpretation included feature importance (close_position — 13%, rsi_lag1 — 10.8%, macd_hist — 9.4%), SHAP analysis (macd_hist as the main differentiator between TP and FP), feature stability over time, and error analysis (FP under high volatility, FN under extreme oversold conditions). Practical insights and recommendations for a trading strategy are formulated. | Python, pandas, numpy, seaborn, matplotlib, scikit-learn, XGBoost, LightGBM, SHAP, statsmodels, phik, TensorFlow/Keras (LSTM) | [Stock Market Dataset for Predictive Analysis](https://www.kaggle.com/datasets/s3programmer/stock-market-dataset-for-predictive-analysis) |
