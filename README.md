|[Stock Market Predictor: прогнозирование направления движения цены](05_Stock_Market_Predictor_OHLCV)| Полный ML-проект по бинарной классификации направления движения цены акции на следующий день на симулированных OHLCV-данных (13 647 торговых дней, 2010–2062). Включает EDA для временных рядов (декомпозиция, ADF-тест, ACF/PACF, сезонность), расширенный feature engineering (лаг-признаки, скользящие окна, технические индикаторы RSI/MACD, сентимент-оценки, календарные признаки). Проведена проверка готовых индикаторов на соответствие стандартным формулам, анализ утечек сентимента. Выполнен отбор 23 стационарных признаков с исключением сырых цен для предотвращения переобучения на тренде. Реализована строгая временная валидация TimeSeriesSplit (train 2010–2045, valid 2046–2053, test 2054–2062) и масштабирование RobustScaler без утечек. Сравнены 5 моделей (LogReg, Decision Tree, Random Forest, XGBoost, LightGBM) с подбором гиперпараметров через GridSearchCV. Лучшая модель — RandomForest (n_estimators=1000, max_depth=9, max_features=5) достигла VALID F1 = 0.634, TEST F1 = 0.684, Recall = 97.1% (поймано 930 из 958 ростов). Оптимальный порог = 0.35 даёт F1 = 0.684. Проведена калибровка вероятностей (Platt scaling, isotonic), выбор порога под разные стратегии (агрессивная, сбалансированная, консервативная). LSTM продемонстрировала F1 = 0.757 на валидации. Выполнена глубокая интерпретация: feature importance (close_position — 13%, rsi_lag1 — 10.8%, macd_hist — 9.4%), SHAP-анализ (macd_hist — главный дифференциатор TP vs FP), стабильность признаков во времени, анализ ошибок (FP при высокой волатильности, FN при экстремальной перепроданности). Сформулированы практические инсайты и рекомендации для торговой стратегии.| Python, pandas, numpy, seaborn, matplotlib, scikit-learn, XGBoost, LightGBM, SHAP, statsmodels, phik, TensorFlow/Keras (LSTM) | [Stock Market Dataset for Predictive Analysis](https://www.kaggle.com/datasets/s3programmer/stock-market-dataset-for-predictive-analysis) |
